Case study 01 · AI application

SecureChatAI

A private AI chatbot SaaS that answers questions from uploaded documents. I tested the conversations, the document pipeline and the access rules.

  • Chatbot conversations, document uploads and processing, authentication and session behaviour
  • Role-based access for Admin, Superadmin and User roles
  • API checks in Postman: developer cURL requests imported, request fields changed, responses validated
  • With client-provided access, verified in Pinecone that document chunking and embeddings were created correctly

Result: 153 test cases written. Of the executed cases, 79 passed, 26 failed and 2 were partial; the remainder were duplicates or not executed.

ClickUp · Postman · Pinecone · JWT · Chrome DevTools

I used LangChain to build a way of testing a chatbot where a second LLM acts as the judge and scores the chatbot's answers. It scales checking beyond what I can read by hand.

What I'm learning: judges can be wrong or biased, so judge scores need spot-checking against my own manual review.
